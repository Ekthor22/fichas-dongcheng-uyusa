# Fichas técnicas DongCheng · Uyusa

App web instalable (PC y Android) para buscar fichas técnicas DongCheng por **SKU Uyusa**, **modelo DongCheng** o nombre, y descargar el **PDF** de la ficha del producto.

- 344 productos DongCheng del portal Uyusa, con logos Uyusa y DongCheng.
- Funciona sin conexión una vez instalada (PWA).

## Uso
Abre la página publicada en GitHub Pages con Chrome o Edge y presiona **Instalar app**.
En Android: menú ⋮ → **Instalar aplicación**.

## Actualizar fichas
Reemplaza `data.json`, `pdf/` e `img/`, y sube la versión del caché en `sw.js` (`fichas-dc-v1` → `fichas-dc-v2`).
